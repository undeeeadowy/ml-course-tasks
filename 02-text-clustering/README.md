# Кластеризация текстов

Обучение без учителя: разбить 14 590 документов (разреженная TF-IDF-матрица 14 590 × 77 888) на группы. Метрика — **Adjusted Rand Score**, считается на стороне организаторов.

## Подход

1. **Разведка данных:** формат матрицы, тип значений (TF-IDF), проверка нормировки строк.
2. **Baseline:** K-means с K = 10 на исходных признаках.
3. **Снижение размерности:** TruncatedSVD (LSA) до 100 признаков + нормировка, затем K-means — *в работе*.

## Результаты (ARS, public)

| Решение | ARS |
|---|---|
| K-means, K = 10, исходные признаки | 0.038 |
| TruncatedSVD-100 + K-means, K = 10 | в работе |

Низкий результат baseline объясняется проклятием размерности: на 77 888 признаках расстояния между объектами почти одинаковы, и K-means плохо находит группы.

## Стек

Python, numpy, scipy, scikit-learn.

## Запуск

Данные (`train.npz`, `sample_submission.csv`) выдаются в рамках курса и в репозиторий не входят. Положите их рядом с `solution.ipynb` и запустите ноутбук сверху вниз.
