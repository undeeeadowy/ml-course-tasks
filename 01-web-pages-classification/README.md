# Классификация веб-страниц: контент 18+

Бинарная классификация веб-страниц по `url` и заголовку `title`. Метрика — **F1-score**.

## Подход

1. **Baseline-правило** «в заголовке есть слово порно» — точка отсчёта. Precision 0.99, но recall всего 0.19.
2. **Мешок слов** (`CountVectorizer`) + **наивный байес** — модель сама находит характерные слова.
3. **Честная валидация**: стратифицированное разбиение 80/20, все решения принимаются по F1 на отложенной части.
4. **url + title** в одном тексте — в адресе часто прямой сигнал.
5. **Логистическая регрессия** вместо наивного байеса.
6. **Подбор порога** вероятности под F1 (выбрана середина плато, 0.3).

## Результаты (F1 на validation)

| Решение | F1 |
|---|---|
| Правило «порно» | 0.312 |
| CountVectorizer + NB, title | 0.910 |
| CountVectorizer + NB, url + title | 0.930 |
| CountVectorizer + LogReg, url + title | 0.964 |
| + порог 0.3 | **0.970** |

## Стек

Python, pandas, numpy, scikit-learn.
