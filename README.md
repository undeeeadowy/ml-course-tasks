# ML Course Tasks

Решения практических задач курса по машинному обучению.

Каждая задача лежит в своей папке: ноутбук `solution.ipynb` с пошаговым разбором (зачем каждый шаг, формулы, выводы по результатам) и `README.md` с кратким описанием.

## Задачи

| # | Задача | Тип | Метрика | Лучший результат | Методы |
|---|---|---|---|---|---|
| 1 | [Классификация веб-страниц 18+](01-web-pages-classification/) | бинарная классификация текстов | F1 | **0.970** (validation) | мешок слов, наивный байес, логистическая регрессия, подбор порога |
| 2 | [Кластеризация текстов](02-text-clustering/) | обучение без учителя | Adjusted Rand Score | 0.038 (public), в работе | TF-IDF, K-means, TruncatedSVD (LSA) |

## Как я работаю над задачей

1. **Разведка данных:** размеры, типы значений, пропуски, баланс классов.
2. **Baseline** — самое простое решение, точка отсчёта.
3. **Честная валидация:** отложенная выборка со стратификацией, все решения — только по ней.
4. **Одно изменение за раз** — чтобы понимать, что именно дало прирост.
5. **Разбор результата:** не только итоговая метрика, но и precision/recall, разрыв train/validation, размеры кластеров.
